# بسته Backend — 3D Market Iran

## محدوده
این بسته فقط برای Repository `3Dmarketiran/backend` است.

## تغییرات موردنیاز
- اعمال سقف‌های سروری پلن‌ها: Starter 10/500MB، نیمه‌حرفه‌ای 30/1536MB، حرفه‌ای 100/5120MB.
- کنترل مصرف تجمیعی Storage سمت سرور، نه صرفاً UI.
- هماهنگ‌سازی حد مدل 50MB و ZIP 150MB.
- حذف فایل‌های محصول بر اساس Prefix شامل GLTF dependencies.
- اجرای سیاست نگهداری 30 روزه پس از پایان اشتراک، فقط در صورت عدم تمدید.
- ثبت عملیات حذف در AuditLog؛ حفظ حساب و داده‌های متنی فروشنده و تبدیل محصول به Draft.
- بررسی و رفع کم‌شماری Package endpoint پیش از کمپین وسیع.
- بررسی `rootDir` و تنظیمات واقعی Render.

## زمان‌بندی حذف
اشتراک منقضی → فایل‌ها تا 30 روز نگهداری → در صورت عدم تمدید، حذف دائمی فایل‌های محصول و لوگو. اجرای Cron روزانه باید پایش شود. Renewal قبل از اجرای purge باید مانع حذف شود.

## فایل‌های همراه
- `src/services/storageCleanupService.ts`
- `src/scripts/cleanupExpiredStorage.ts`
- Migration همگام‌سازی پلن‌ها
- Patch یکپارچه Backend

## احتیاط
این فایل‌ها هنوز به‌معنی Deploy یا تست Production نیستند. ابتدا Branch پشتیبان، بررسی diff، تست روی DB/Storage آزمایشی، سپس Migration و Deploy. حذف دائمی باید با تأیید مالک محصول و تست بازیابی/بکاپ انجام شود.
